# VSCode Snippet Manager - Webview UI

A modern, responsive web interface for managing VSCode snippets, built with React and TypeScript.

## 🚀 Features

- **Snippet Management**: Create, edit, and organize code snippets
- **Folder Organization**: Group snippets into custom folders
- **Syntax Highlighting**: Uses react-syntax-highlighter for syntax highlighting
- **Responsive Design**: Works across different screen sizes
- **Themeing**: Matches VSCode's theme
- **Fast Search**: Quickly find snippets with powerful search capabilities

## 🛠️ Tech Stack

- **Frontend**: React 19 with TypeScript
- **State Management**: Redux Toolkit
- **Styling**: Tailwind CSS
